**Project Task:**

Your report should follow the following format/order (use the word template from Assignment 1 and tailor as per following sections below).

- (i) Title of the report
- (ii) Student Names (along with UTS Student ID)
- (iii) Executive Summary (100-250 words)
- (iv) Introduction – Overview of description of the problem that you are trying to solve with your project. That is, what are the high-level goals of the code that you have implemented in the Lab Environment (300-400 words)
- (v) Solution Design (No words limit)
  - a. Solution Architecture
  - b. Conceptual Model of Data Entities
  - c. Logical Data Model of Data Entities
  - d. Design Rational (why you choose the given design, e.g., use case fit, performance, complexity, cost)
  - e. Design Trade-offs
- (vi) Working Prototype Implementation using the provided Lab Environment (No words limit)
  - a. Databases and schemas of source systems (at least 3 data sources)
  - b. Integrated data warehouse databases and schema (at least 1)
  - c. SQL Scripts with synthetic data for creating databases, schemas, extracting data from source systems and transforming/loading into the data warehouse. This should be fully commented, ready for execution without errors. This should be clearly mapped to the solution design components.
  - d. Reports and dashboard as per data use case (at least 3) for your project with synthetic data.
  - e. End-to-end testing and provide a link in the report to access a recorded end-to-end testing demo video of the working prototype. You may post video demo to your GitHub or YouTube.
- (vii) Report Summary/Conclusion (200-300 words)
  - a. Present an overall summary of the contents presented in this report about the design and implementation.
- (viii) Appendix (No Limit)
  - a. Include an appendix (at the end of the report) containing the evidence of individual student's contribution (contents from individuals' contribution logbooks) to teamwork and communication (e.g., email communication, tasks allocated, performance by the individuals in the group assignment), and the meeting minutes (at least 3, signed by teacher).
